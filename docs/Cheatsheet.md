# Cheatsheet

## 󰘳 App Launcher

| Key              | Action                         |
| ---------------- | ------------------------------ |
| `Escape`         | Clear input and close launcher |
| `Return / Enter` | Launch selected application    |
| `↑ / Ctrl+K`     | Move up                        |
| `↓ / Ctrl+J`     | Move down                      |
| `← / Ctrl+H`     | Move left                      |
| `→ / Ctrl+L`     | Move right                     |

## Clipboard Manager

| Key                      | Action                                       |
| ------------------------ | -------------------------------------------- |
| `/`                      | Activate search field                        |
| `Escape / Q`             | Close clipboard manager/Unfocus search field |
| `↓ / J`                  | Move down in history                         |
| `↑ / K`                  | Move up in history                           |
| `Return / Enter`         | Copy selected item                           |
| `G`                      | Go to top of list                            |
| `D`                      | Delete current item                          |
| `0-9`                    | Quick paste from slot                        |
| `Ctrl + 0-9`             | Store item to slot                           |
| `Ctrl + Click`           | Store item in next slot                      |
| `Shift + Click`          | Delete item                                  |
| `Right Click Button 0-9` | Delete item                                  |
| `Left Click Button 0-9`  | Copy item                                    |
| `Alt + D`                | Clear all slots                              |

## 󰕾 Mixer

| Key          | Action                  |
| ------------ | ----------------------- |
| `Escape / Q` | Close mixer             |
| `↓ / J`      | Next audio device       |
| `↑ / K`      | Previous audio device   |
| `← / H`      | Decrease volume (5%)    |
| `→ / L`      | Increase volume (5%)    |
| `M`          | Toggle mute/Toggle play |

## 󰂚 Notification Manager

| Key          | Action                     |
| ------------ | -------------------------- |
| `Escape / Q` | Close notification manager |
| `C`          | Clear all notifications    |

## 󰐥 Power Menu

| Key              | Action                  |
| ---------------- | ----------------------- |
| `Escape / Q`     | Close power menu        |
| `← / H`          | Option Left             |
| `→ / L`          | Option Right            |
| `Return / Enter` | Execute selected action |

## 󰖯 Toplevel View

| Key           | Action                                   |
| ------------- | ---------------------------------------- |
| `Escape / Q`  | Close toplevel view                      |
| `Letter Keys` | Jump to window starting with that letter |
| `Ctrl`        | Toggle Local/All                         |
| `Alt`         | Next Toplevel                            |
| `Tab`         | Previous Toplevel                        |

## Workspace Switcher

| Key           | Action                                    |
| ------------- | ----------------------------------------- |
| `Escape / Q`  | Close workspace switcher                  |
| `Letter Keys` | Switch to workspace mapped to that letter |

## 󰌾 Polkit

| Key      | Action                |
| -------- | --------------------- |
| `Escape` | Cancel authentication |
